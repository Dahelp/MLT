# Country boundaries

Simplified ADM0 boundaries for Italy, Austria and Germany are sourced from the geoBoundaries `gbOpen` API.

- Source: https://www.geoboundaries.org/api.html
- Dataset: geoBoundaries
- Files: `italy.geojson`, `austria.geojson`, `germany.geojson`
- Licenses are declared by the respective national data sources in the geoBoundaries metadata.
