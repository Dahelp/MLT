MLT Scout Passport

Форма для скаутов: https://mlt-lifestyle.com/scout-passport/
Модерация: https://mlt-lifestyle.com/admin/base-location/

Языки публичной формы: /en/scout-passport/, /de/scout-passport/,
/ru/scout-passport/, /it/scout-passport/, /pl/scout-passport/.
Исходная ссылка /scout-passport/ сохраняет русскую версию.
Язык выбирается в общей шапке сайта; при переключении сохраняются
черновик, фото, видео и персональная ссылка с ключом. Интерфейс Base location
использует текущий язык админки: EN, DE или RU.
На десктопе форма расширена до 1440 px и размещена в две колонки,
на телефоне — в одну. Вступительный блок убран во всех языках.
Переводы интерфейса и ошибок: public/data/scout-i18n.json.

Форма доступна по ссылке без регистрации. Скаут вводит своё имя, категорию,
название места, страну/регион, координаты, описание, парковку и бронирование.
Кнопка GPS запрашивает текущую геопозицию телефона; при отказе координаты
можно заполнить вручную. При добавлении фото сначала выбирается источник:
«Открыть камеру» либо «Выбрать фото из галереи». Камера не запускается
автоматически. Вход галереи не имеет capture; отдельный резервный вход
камеры телефона имеет capture=environment. Для отправки нужны 2–4 фото.
Перед сохранением кадр 3:4 можно перемещать пальцем и масштабировать;
для точной настройки есть ползунки положения и сброс. Сохраняется именно
показанная область как JPEG 900 x 1200. Исходное фото — до 25 МБ.

Видео необязательно: один ролик до 50 МБ, MP4, MOV или WebM.
«Выбрать видео из галереи» и «Снять видео» — разные кнопки и разные
файловые входы. Вторая вызывает штатную видеокамеру телефона через
capture=environment; на компьютере браузер может показать выбор файла.
До отправки доступны предпросмотр, замена и удаление видео. В Base location
видео видно администратору внутри подробностей карточки с проигрывателем
и ссылкой на файл. Оно не добавляется автоматически в публичные точки карты.

Черновик вместе с фотографиями и исходным файлом видео сохраняется в
IndexedDB этого браузера. При недоступном хранилище показывается сообщение.
После отправки скаут получает номер карточки и персональную ссылку.
По ней можно обновить статус и открыть карточку, возвращённую на доработку.
Ключ находится в URL после #; хранить и пересылать полную ссылку следует
только скауту, которому принадлежит карточка.

Base location доступен только администратору. Действия:
- Принять: одобрить карточку без автоматической публикации.
- Отклонить: отклонить карточку и снять опубликованную точку с карт.
- Доработать: указать обязательный комментарий, вернуть скауту и снять
  опубликованную точку с карт. Скаут может открыть свою сохранённую ссылку.
- Создать и скопировать ссылку на доработку: получить новую персональную
  ссылку для отправки скауту. Предыдущая персональная ссылка аннулируется.
- Загрузить на карты: опубликовать принятую карточку в mlt_route_points.
- Убрать с карт: отключить точку, сохранив карточку и решение модерации.

Опубликованные точки читаются всеми картами сайта, списками выбранных мест,
картами личного кабинета и выбором точек у консьержа. Уже открытые карты
обновляют каталог раз в минуту, при возврате на вкладку или перезагрузке.
В Каталог / Точки маршрута точка доступна для добавления в маршруты.
Повторная публикация обновляет ту же точку и не создаёт дубликат.
Повторная отправка после сетевого сбоя также не создаёт новую карточку.

Технически: public/api/scout.php, public/api/scout-core.php,
public/api/scout-video.php; таблица mlt_scout_submissions создаётся
автоматически в существующей БД, поле video_json добавляется к прежним карточкам.
Фото сохраняются в public/uploads/scout (случайные имена JPEG/WebP).
Видео — в public/uploads/scout-video под случайными именами; настройки
размера и частей — public/data/scout-media.json. Передача идёт частями
по 768 КиБ через существующий JSON API, без повышения лимита HTTP-запроса.
mlt_scout_video_uploads хранит смещение, ключ владельца и связь с карточкой.
Повторные старты и части идемпотентны; после сбоя следующая отправка
продолжает загрузку. MIME проверяется по содержимому. Файлы .part закрыты
Apache; незакреплённые загрузки старше двух суток удаляются ограниченными
порциями при новом старте. Прикреплённые видео эта очистка не затрагивает.
При переносе/резервном копировании сохранять БД и каталог uploads.
Нужны существующие PHP PDO MySQL, mbstring и fileinfo. GD используется
только изолированными тестами для подготовки фотографий.
Камера и GPS разрешены заголовком Permissions-Policy только для страницы
/scout-passport/ и для всех пяти языковых адресов. Нужны HTTPS и разрешение пользователя в браузере.

Проверки:
pnpm test
node --test tests/scout-api.test.mjs tests/scout-media.test.mjs tests/apache-security.test.mjs
node scripts/export-static.mjs

При проверке на реальном телефоне: открыть публичную ссылку в Safari/Chrome,
разрешить геопозицию и камеру, проверить координаты на месте, сделать два
снимка, выбрать фото из галереи, изменить обрезку и отправить карточку.
Отдельно проверить обе кнопки видео в Safari/Chrome на самом телефоне:
галерея и запись нового видео, включая звук штатной камеры. Проверить
восстановление черновика и повторную отправку при потере связи. Затем
проверить фото и воспроизведение видео в Base location.
