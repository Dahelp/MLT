Переводы существующих карточек мест

Для 23 опубликованных карточек подготовлены версии на EN, DE, RU, IT и PL.
Данные: public/data/map-place-translations.json. Переведены заполненные
описания, парковка/заезд, бронирование и удобства. Официальные названия,
координаты, фотографии, видео, рекомендации, сайт и телефон не меняются.

Это разовый редакционный перевод. Внешний сервис автоматического перевода
новых заявок не подключён. Исходные данные в базе остаются без изменений.

API scout.php добавляет translations только для опубликованных мест.
scout-core.php сверяет каждое поле с сохранённым source в каталоге. Если
скаут или администратор изменит поле, его прежний перевод больше не отдаётся;
карта показывает обновлённый оригинал. Переводы остальных полей сохраняются.
Изменение фотографий, рекомендаций или контактов не отменяет переводы текста.

Для обновления перевода нужно внести актуальный оригинал в source нужной
карточки и заполнить соответствующее поле во всех пяти translations.
Пустые поля остаются пустыми. Не добавлять неподтверждённые сведения.

React сохраняет оригинал в RoutePoint и выбирает перевод через
localizedRoutePoint при открытии карточки на выбранном языке сайта.
Каталог выкладывается на хостинг до обновлённого обработчика API.
